# LM Motors : site web

Projet de site pour **LM Motors**, garage automobile, rue Robert Raclot, 89290 Champs-sur-Yonne (Yonne). L'objectif est un site qui génère des clients : appels, demandes de devis, rendez-vous, avis.

## Recherche préalable (`recherche/`)

| Fichier | Contenu |
|---|---|
| [`recherche/dossier-lm-motors.md`](recherche/dossier-lm-motors.md) | Dossier complet et sourcé : identité, coordonnées, présence en ligne, concurrence, zone de chalandise, pièges et homonymes, recommandations |
| [`recherche/donnees-verifiees.json`](recherche/donnees-verifiees.json) | Faits vérifiés, en données structurées, à utiliser pour construire le site |
| [`recherche/questions-gerant.md`](recherche/questions-gerant.md) | Questionnaire à faire remplir par le gérant (tout ce qui est introuvable en ligne) |

Règle : **aucune information inventée**. Ce qui est inconnu (téléphone, horaires, numéro de rue…) reste vide tant que le gérant ne l'a pas fourni.
